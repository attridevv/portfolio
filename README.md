# attridevv.com

My portfolio — **[attridevv.com](https://attridevv.com)**.

Hand-built static site: plain HTML, CSS and JavaScript, no framework and no build step. Deployed to GitHub Pages by `.github/workflows/deploy.yml` on every push to `main`.

```
index.html        work site
404.html          not-found page
assets/work/      project screenshots
hire/             freelance page (draft)
aka/              private page — content is encrypted (AES-256-GCM)
scripts/seal.mjs  encrypts the private page
```

Preview locally: `python3 -m http.server 8000`
